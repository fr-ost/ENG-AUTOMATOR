# ENG-AUTOMATOR
Automated daily X (Twitter) post discovery and promotion management using Python, GitHub Actions, the official X API, and SMMSOC API integration. Features include post URL extraction, duplicate prevention, campaign planning, API status checks, daily reports, and optional Telegram notifications.

## Project

The bot lives in [`x-daily-automation/`](x-daily-automation/README.md); its workflow is [`.github/workflows/daily.yml`](.github/workflows/daily.yml). Start with the [setup guide](x-daily-automation/README.md).
